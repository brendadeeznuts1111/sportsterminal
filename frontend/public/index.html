Recovery Matrix

          

            

              
401 Unauthorized

              
Buckeye token expired. Auto-renews every 15 min. If renewal fails,
                falls back to password re-login (max 3 attempts). After 3 failures, broadcasts auth_failed
                and stops polling.

            

            

              
Network Timeout

              
Buckeye API unreachable. Exponential backoff: 5s → 10s → 20s → 40s →
                max 60s. Resets to 5s on next success. Consecutive errors tracked per agent.

            

            

              
Rate Limit (429)

              
Server-side rate limiter: 100 req/min per IP. Returns
                Retry-After header. Client should back off. No automatic retry — user must wait.
              

            

            

              
DB Constraint Violation

              
INSERT OR IGNORE on wager_archive prevents duplicate wager_number
                errors. Transactions roll back cleanly on failure. RawApiLogger catches and logs silently.

            

            

              
WebSocket Disconnect

              
Client auto-reconnects (max 5 attempts, 3s delay). Server pings every
                30s, closes stale connections after 45s. Auth state restored via JWT token.

            

            

              
RawApiLogger Failure

              
Fire-and-forget design. Logging errors are caught and logged to
                console only — never propagated to the caller. Queue flushes every 250ms or 25 items.
